класс tabledata - общий класс для элементов таблицы
аттрибут data-price - цена товара
аттрибут data-price-sub - разница на вторую цену
класс length - длина
класс price - цена1
класс price2 - цена2

В функции recalc надо задать соответственно все эти дела
var allItemsClass = 'tabledata';
var lengthId = 'length';
var weightId = 'weight';
var price1Class = 'price1';
var price2Class = 'price2';

Фильтр

<div class="select">
    <a onclick="filter(this,'tabledata')" class="all active">Все</a>
    <a onclick="filter(this,'a12')">А12</a>
    <a onclick="filter(this,'ct10')">СТ10</a>
</div>

класс select - класс родителя списка фильтров
класс all - класс идентификатор всех фильтров
класс active - активный фильтр
Второй параметр фильтра - это соответствующий класс который хотим отобразить.
