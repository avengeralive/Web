PHPMyExplorer
Версия 1.0а-developing

Предназначение

PhpMyExplorer - это набор пхп скриптов, предназначенных для манипулирования файлами 
на сервере провайдера по протоколу http(https).
В большинстве случаев - это полноценная замена FTP, SCP и командной строки (а иногда и больше:).
Работает под (unix/linux/winnt)+apache+php.

Краткий обзор возможностей

Просмотр списка файлов/директорий, типа, размера, даты модификации. Сортировка по необходимым параметрам.
Просмотр дерева папок.
Поиск файлов по имени(регулярному выражению).
Просмотр/редактирование/выкачка/закачка для любого файла(файлов).
Применение определяемых функций (как встроенных так и плагинов) сразу для групп файлов.
Архивирование "на лету" выкачиваемых файлов.
Механизм авто-бэкапов при редактировании файлов.
Механизм проверки корректности настроек.
Поддержка пользовательских плагинов, php-консоль.
...и другое.

Установка

1 Создайте папку (например, /admin/explorer).
2 Установите требуемые права (в .htaccess или http.conf) для доступа к этой папке "снаружи".
3 Распакуйте архив.
4 Настройте константы в файле adm_explorer_setting.php (4 пути).
5 Запустите файл check.php и проверьте все ли работает правильно. При необходимости измените
  требуемые параметры (в поставке идет файл .htacess с рекомендуемыми параметрами настроек сервера apache и языка php)
6 Пользуйтесь.

Что к чему (прототип мануала)

Функции применяемые с списку файлов (папок):
	PHPZIP+загрузить - создание зип файла и отсылка его в браузер к закачке
	Удалить - удаление файла/папки
	Plugin::view_images - просмотр картинок
	Plugin::restore_backups - переименование файлов вида старое_имя.backup в старое_имя

Функции применяемые с папке:
	Plugin::folder_usage - сканирование директории и построение статистики по кол-ву файлов, занимаемому пространству и т.п.
	"Дерево папок" - строит дерево папок для директории, пишет кол-во файлов и размер папок.
	"Поиск" - поик файлов чье имя удовлетворяет введенной подстроке (рег. выражению)
	"Закача файлов" - закачка файлов в эту директорию.

Функции применяемые с одному файлу:
	"Клик на файл" - отсылка файла в браузер
	[v] - просмотр файла в браузере
	[e] - редактирование файла (помните про 64 кб ограничение).
